# Steps to convert source code to an executable

1. Preprocessing (done by a preprocessor): resolves directives (start with "#") editing the given source code.
  * Directives are editing commands that modify the source code prior to compilation.

2. Compiling: a compiler produces object files containing machine instructions from source code files.

3. Linking: a linker combines the object code files with with any additional code such as libraries
  to a complete executable file.
