# C Learning Plan

## Phase 1: Core C (months 1-3)

* C Programming: A Modern Approach book
  * Do exercises daily
  * Focus on topics like pointers/memory/arrays

## Phase 2: System Programming (months 3-8)

* The Linux Programming Interface book
* Develop simple CLI tools

## Phase 3: Depth in one direction (months 8-14)

Choose a domain and build something real:
* Develop/contribute to a PostgreSQL extension
* Contribute to an existing Linux CLI tool/library
* Contribute to PostgreSQL itself
